Install in four steps.

About five minutes. You only do this once; after that the app updates itself.

1

Download the installer

If your download didn't start, download ShortsStudio-Setup.exe.

Windows 10 or 11, 64-bit.

2

Get past the Windows warning

Open the file. Windows shows a blue "Windows protected your PC" box because the app is new and not signed yet.

Click More info, then Run anyway. You only see this once.

3

Choose fast or custom install

Fast install puts everything in the usual places. Click Install and you're done.

Custom install lets you pick where the app goes and where your projects and renders are saved. Renders get big, so a roomy drive helps.

4

Connect your Claude plan

Shorts Studio uses Claude Code with your own Pro or Max plan. Open PowerShell and run these two lines. The second one opens Anthropic's sign-in page in your browser.

The app checks this for you on first start and shows the same steps if anything is missing.

irm https://claude.ai/install.ps1 | iex
claude auth login

All set? Open Shorts Studio.

It opens in your browser at localhost:4870 and sits in the tray while it runs.
